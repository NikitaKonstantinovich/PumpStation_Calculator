# Выбор конструкции и высоты рамы

Граф продукта выбирает конструкцию по подтверждённой массе одного насоса. Для общей рамы нескольких активных контуров используется масса самого тяжёлого отдельного насоса. Если выбор или корректная масса хотя бы одного активного насоса отсутствуют, автоматический выбор рамы остаётся неполным.

| Масса насоса m, кг | Конструкция | Высота, мм |
| --- | --- | ---: |
| 0 < m < 50 | Гнутая рама, лист 4 мм | 50 |
| 50 ≤ m < 100 | Гнутая рама, лист 5 мм | 50 |
| 100 ≤ m < 300 | Швеллер 8П | 80 |
| 300 ≤ m < 500 | Швеллер 10П | 100 |
| 500 ≤ m < 1000 | Швеллер 12П | 120 |
| m ≥ 1000 | Швеллер 14П | 140 |

## Компоновка и стоимость

Выбор по массе определяет сечение и высоту. Если к спецификации подключён расчёт рамы, он использует схему установки, координаты опор оборудования и закреплённые детали и тарифы. Для гнутой рамы рассчитываются заготовка, крепёж и монтажные отверстия. Швеллерная ветвь определяет длины элементов, отверстия, крепёж, сварку и окраску. [Гнутая рама](bent-frame-calculation.md) · [Швеллерная рама](horizontal-channel-frame.md)

В спецификации откройте позицию «Рама-основание», чтобы проверить подробности. При неизвестных размерах, ценах или исполнениях проверьте причины незавершённости. Когда рассчитана геометрия швеллерной рамы, меню «Выгрузить» содержит чертёж SVG.

В 3D расчётная высота привязывает оборудование к верхней плоскости рамы. При нехватке данных условная высота для просмотра составляет 80 мм. После смены насосов или закреплённых справочников проверьте расчёт и обновите компоновку. [3D-редактор](3d-editor.md)
