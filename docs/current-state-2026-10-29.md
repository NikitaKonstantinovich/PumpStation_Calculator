# Состояние приложения на 29.10.2026

Версия пакета — `0.1.0-beta.1`. Документ описывает исходники текущей версии,
а не доступность удалённого сервера. Профиль `full` содержит все инструменты
с ограничениями по роли; beta — подбор, кривую, карточку насоса, базу
комплектующих и администрирование пользователей для admin.

## Реализовано

- Каталог: 5 856 насосов, 5 039 доступны для подбора, 54 423 точки Q/H,
  шесть производителей, включая LEO XST. Количество сверено с
  `public/pumps.json` и `data/pump-catalog/merge-report.json`.
- Этап 1 спецификации: единая синхронизация выбранных насосов и обвязки,
  миграция старых проектов, независимые состояния полноты и готовности,
  исключение устаревших сумм.
- Этап 2: включение сохранённых расчётов вставок в состав станции,
  ревизии исходных данных, развёрнутый состав деталей и работ.
- Этап 3: КИП по схеме управления, преобразователи давления, баки,
  заглушки и разделительные затворы, реестр портов коллекторов.
- Конструкция и высота рамы по массе самого тяжёлого отдельного насоса
  активных контуров; ручная компоновка 3D сохраняется.
- 3D-ветви всаса/напора, вставки, отверстия и седловые врезки коллекторов,
  виброкомпенсаторы, кронштейны Dendor и по два EKF TZ-8111 на затвор.
  Для Dendor 017W рукоятка применяется до DN150 включительно;
  от DN200 сохраняется редуктор.
- Роли `base/plus/pro/admin`, миграции `0000`–`0010`, CSV/XLSX,
  отдельные сборки beta/full и локальные Worker-серверы с D1.

При подготовке публикации обновлены README и тематические инструкции:
пометки о неопубликованных расширениях заменены фактическим описанием
профилей. Датированные исходные исследования и старые результаты проверок
сохранены как история.

## Ограничения

Программная интеграция этапов 1–3 не подтверждает полноту исходных данных.
Недостающие размеры, давления, цены и выбранные исполнения требуют уточнения;
расчёт варианта не означает наличие изделия в рабочей D1.

У рамы определены конструкция и высота, но не окончательные габариты,
отверстия, расчёт прочности, полный состав и стоимость. Внешняя электрика,
окончательный выпуск и остальные этапы описаны в
[плане спецификации](specification-development-plan-2026-10-28.md).
Алгоритм нативной сборки SOLIDWORKS остаётся предложением.

Исходные CAD и подготовленная большая библиотека хранятся локально.
Повторная подготовка описана в [инструкции конвертера](model-converter.md).
Модели не масштабируются вместо подтверждения размеров; неподтверждённые
посадки остаются предварительными. Отдельная проверка требуется для
срабатывания концевиков и окончательного монтажа.

## Проверка перед публикацией

Заключительный прогон 29.10.2026:

| Проверка | Результат |
| --- | --- |
| `PSC_RELEASE_PROFILE=beta`, `npm run check` | TypeScript, ESLint и сборка успешны; 661 JS-тест, без ошибок и пропусков |
| Python `unittest discover` с OpenCascade | 67 тестов, без ошибок и пропусков |
| `npm run build:full` | Полная версия собрана, проверка выпуска успешна |
| Локальные ссылки Markdown | README, тематические документы и README каталога: отсутствующих целей нет |

Python-набор выполнен в окружении с зависимостями
`services/model-converter/requirements.txt`; тесты используют временные
данные, а не учётные записи и проекты основной D1.

При первом прогоне обнаружены и исправлены несовместимости проверок
с расширенным каталогом (добавленные переходы Ст20 и другие комплектующие)
и подключением компонента гидравлических опций в тесте рендера спецификации.
Из beta-сборки исключена сгенерированная папка CAD-моделей: крупные локальные
STL превышали допустимый размер статического ресурса Worker и мешали запуску.
Исходные модели и профиль full сохранены.

В ограниченном окружении Windows проверки временных файлов, HTTP и завершения
дочерних процессов были недостоверны; повторный запуск выполнен с обычными
правами пользователя и отдельным временным каталогом внутри `work/`.

## Локальный запуск

Команды для новой базы, dev и собранной полной версии на порту 3000 —
в [README](../README.md). Предпросмотр full использует существующую
`.wrangler/state`, не выполняет миграции и не пересоздаёт данные.
Публикация кода в Git не обновляет работающую beta на порту 3005.
