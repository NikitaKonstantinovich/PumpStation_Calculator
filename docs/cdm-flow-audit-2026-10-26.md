## Основание проверки

[Руководство CNP CDM/CDMF, стр. 23](https://cdn.lunda.ru/catalog/binary/document/re_cdm02072025_d37020.pdf)
обозначает стрелки на нижнем корпусе как указатели потока жидкости. Стрелка
на кожухе вентилятора относится к вращению двигателя (стр. 31–32).

Каждый файл заново открыт в OpenCascade, проверены SHA-256 исходного и
нормализованного STEP. На боковых поверхностях нижнего гидравлического корпуса
распознавался контур стрелки: хвост, две внутренние и две наружные точки плеча,
одна вершина. У подтверждённых моделей обе стороны корпуса дают одинаковое
направление. В отчёте сохранены номера граней и измеренные координаты вершин.
Семейство или имя файла не использовались для назначения направления.

Проверены также жёсткость преобразования координат, положение входа в нуле,
соосность патрубков и соответствие всех 302 браузерных профилей своим STEP/STL.
Старый статус `normalized_verified` подтверждал преобразование геометрии,
но не определение гидравлического входа: старое правило выбирало отрицательный X
для всей серии. Поэтому записи исходного индекса нельзя считать подтверждением
направления; актуальную проверку задаёт `data/cdm-flow-registry.json`.

## Исправление и использование

Для 79 моделей созданы отдельные STEP в
`Equipment/Pumps/3D_FlowVerified/vertical_multistage/CNP/CDM/`.
Исходные STEP и старые нормализованные копии сохранены. Выполнено жёсткое
преобразование `x' = L - x; y' = -y; z' = z`, то есть поворот на 180° вокруг
вертикальной оси через середину между патрубками. Отражения и масштабирования нет.
Вход остаётся `[0,0,0]`, выход `[L,0,0]`, поток направлен по `+X`.

STL преобразованы тем же поворотом, включая нормали; порядок вершин треугольников
сохранён. Каждая исправленная CAD-копия повторно импортирована: число граней и тел
сохранилось, габариты совпали с расчётным поворотом, обе стрелки направлены по `+X`.
Реестр подключён к общей функции `load_library`, поэтому команда подготовки
из приложения и CLI используют одинаковые исправленные исходники.

В существующем проекте **перезагрузите страницу и нажмите «Обновить состав»**.
Обновляются ресурсы насоса и сведения о проверке; ручные положения, повороты,
видимость, прозрачность, фиксация и компоновка сохраняются. Если насос ранее
вручную разворачивали для компенсации этой ошибки, его поворот потребуется
перепроверить. Опорные точки на поверхностях корпуса также требуют проверки
после изменения ориентации самой геометрии.

Старый результат задания конвертации не может заменить исправленный профиль
его предшествующей версией. Неподтверждённые модели CDM120/CDM150 сохраняют
предварительные патрубки и отдельное предупреждение о направлении. Существующие
предупреждения об исполнении, монтажной пригодности и расхождении с каталогом
сохранены. Проверка стрелок не является проверкой всей монтажной пригодности.

Для опубликованного приложения нужны обновлённые код, manifest и STL.
На сервер конвертации нужно перенести новый реестр и каталог `3D_FlowVerified`,
затем перезапустить сервис. Python/OCP внутри Cloudflare Workers не требуется.

## Воспроизводимость и результаты

Из `frontend`, используя Python с установленным OCP:

```powershell
python scripts/audit-cdm-flow.py --output artifacts/cdm-flow-audit-2026-10-26 --workers 4
python scripts/prepare-cdm-flow-review.py --audit artifacts/cdm-flow-audit-2026-10-26/report.json
python scripts/verify-cdm-flow-review.py --corrections artifacts/cdm-flow-audit-2026-10-26/corrections.json --workers 4
python scripts/activate-cdm-flow-review.py --directory artifacts/cdm-flow-audit-2026-10-26
```

Подготовка пишет отдельные копии и черновики. Активация требует успешной проверки
всех исправленных STEP, сверяет хеши STEP/STL и не перезаписывает параллельные
изменения CDM-профилей. Остальные записи manifest сохраняются.

- [Таблица всех 379 файлов](../artifacts/cdm-flow-audit-2026-10-26/models.csv).
- [Повторная проверка 79 исправленных CAD-копий](../artifacts/cdm-flow-audit-2026-10-26/verification.json).
- [Покрытие каталога и 72 модели без STEP](../artifacts/cdm-flow-audit-2026-10-26/catalog-coverage.json).
