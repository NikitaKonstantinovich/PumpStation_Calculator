# Крепёж обратных клапанов, затворов и фланцев по DN/PN

Сверено непосредственно с листом «Полезная инфа» 2 октября 2026 года.

## Источники и область применения

Принятый источник размеров по DN/PN и длин крепежа — лист «Полезная инфа»
книги `Equipment/Калькулятор по ОБВЯЗКЕ.xlsm`. Лист «Метизы» используется
как зависимость её формул для размеров гаек/шайб и как каталог изделий.
Таблицы прежнего калькулятора не используются для выбора крепежа.
В локальной распаковке имя XLSM повреждено,
но SHA-256 файла совпадает с исходником в
[`public/binding-components.json`](../public/binding-components.json):
`f68b4519e1e6786982e026472d49553d70159e87154417c02f53b9ced3a1464c`.

В книге приведены размеры для фланцев из стали 20 и следующих исполнений:
затвор 017W, межфланцевый обратный клапан 10С, задвижка 47GV,
фланцевый шаровой обратный клапан 012F. Данные конкретных исполнений
не распространяются автоматически на другие модели арматуры и AISI304.

Число отверстий, диаметр крепежа и толщины фланцев включены в приложение:
[`app/suction-fasteners.json`](../app/suction-fasteners.json), экспорт
[`scripts/export-suction-fasteners.py`](../scripts/export-suction-fasteners.py).
Длины для арматуры ниже прочитаны непосредственно из XLSM; отдельной готовой
таблицы этих длин в указанном JSON нет.

## Резьба и количество крепежа

Источник: «Полезная инфа»!B51:I70. Ячейка таблицы имеет вид
**резьба / количество отверстий одного фланца**. Количество отверстий равно
числу стяжек одного межфланцевого узла или болтов одного фланцевого стыка.

В каталоге «Метизы» указан болт DIN933, гайка DIN934 и плоская шайба DIN125
с соответствующим номинальным размером M. Обозначение «Ц 8,8» сохранено
в исходных наименованиях; это не отдельная проверка материала или класса
прочности каждого изделия.

По формулам книги комплектация одного узла различается:

| Узел | Стяжки / болты | Гайки DIN934 | Шайбы DIN125 | Прокладки |
| --- | --- | --- | --- | --- |
| Межфланцевый затвор 017W | n болтов | n | n | 2 на затвор; их толщина не включена в исходную формулу длины |
| Межфланцевый обратный клапан 10С | n стяжек с двумя резьбовыми концами | 2n | 2n | 2 на клапан, включены в исходную формулу длины |
| Фланцевый обратный клапан 012F или задвижка 47GV, оба конца | 2n болтов | 2n | 2n | 2 на изделие |

Для 10С две гайки и две шайбы на стяжку следуют из формулы длины
«Полезная инфа»!F126:H142. Это вывод из формулы листа;
для такого пакета текущая программа использует тип крепежа `stud` (шпилька).
Количество для станции умножается на число одинаковых узлов, включая резервные
насосы, если они имеют такую же обвязку.

## Длины крепежа затвора 017W и обратного клапана 10С

Длины в мм сохранены **как в исходной книге**, без округления до ассортимента.

## Ограничения исходных формул и расчёт приложения

1. Формулы книги ищут размеры гаек только в «Метизы»!E108:G113 и шайб
   в E129:G134, то есть до M30. Для M33/M36/M42/M45 `IFERROR` подставляет
   ноль, хотя размеры есть в следующих строках каталога. Поэтому длины со `*`
   занижены. Например, DN500/PN25: затвор 017W — 236 мм в книге;
   формула с имеющимися размерами гайки 26 мм и шайбы 5 мм дала бы 267 мм
   ещё до учёта прокладок. Для клапана 10С — 270 мм в книге против 332 мм
   при восстановлении двух гаек и двух шайб в той же формуле.
2. Формула 017W учитывает два фланца, корпус затвора, одну гайку, одну шайбу
   и выступ резьбы 5 мм, но пропускает толщину двух прокладок. Формула 47GV
   также пропускает толщину прокладки одного стыка. Формула 10С
   учитывает два фланца, корпус, две гайки, две шайбы, две прокладки по 2 мм
   и два выступа резьбы по 5 мм. Константы — «Полезная инфа»!C193 и C195.
3. Таблица «Длина болтов соединение два фланца» P51:R66 в книге фактически
   прибавляет толщину только одного фланца. P67:R70 содержат записанные числа.
   Эти длины используются конструктором для длины патрубка (см.
   [документацию конструктора](collector-constructor.md)), поэтому их нельзя
   переносить в подбор крепежа без проверки пакета соединения.
4. Общая функция [`app/line-spec-parts.ts`](../app/line-spec-parts.ts)
   при подборе болта учитывает суммарную толщину двух фланцев, межфланцевого
   элемента и прокладок по 2 мм. Тип `bolt` учитывает одну гайку, одну шайбу
   и выступ 5 мм; тип `stud` — две гайки, две шайбы и два выступа по 5 мм.
   Функция выбирает самый короткий крепёж соответствующего типа из каталога
   длиной не меньше расчётной. Напорная линия уже передаёт `stud` для 10С,
   собственную длину его корпуса и толщину фланца 012F.
   Для 017W результат этой формулы на 4 мм больше табличной длины листа:
   DN100/PN16 — 129 мм в расчёте против 125 мм в G83. Это различие требует
   явной обработки при приведении программы к принятому источнику.
   Сопоставление модели арматуры, DN/PN, типа стыка и статуса комплекта
   следует проверить по промпту выше; наличие записи с ценой само по себе
   не подтверждает корректность подбора.

В рамках добавления этой документации исходная книга, справочники и
инженерные формулы приложения не изменялись.

## Другие фланцевые исполнения из той же книги

Длина болта относится к **одному стыку** ответного фланца с фланцем арматуры.

не входит. Для крепления обоих концов требуется два комплекта по n болтов.
