# Закрытая beta 0.1

Версия пакета: `0.1.0-beta.1`. Отображаемая версия: **beta 0.1**.

Сохранён интерфейс полной версии: меню, лента, свободные окна, сетка, Mobile,
сворачивание, отдельные вкладки, оформление. В списках видны все инструменты;
закрытые пункты отключены с подписью «Недоступно в beta 0.1».

Для **base, plus, pro и admin** доступны четыре расчётных инструмента:

| Инструмент | Доступ |
| --- | --- |
| Подбор насосов (`input`) | Ввод, подбор, фильтры, выбор модели |
| Гидравлическая кривая (`chart`) | Построение, методы кривой, экспорт |
| Карточка насоса (`sketch`) | Характеристики, чертежи, существующий экспорт |
| База комплектующих (`components`) | Просмотр, поиск и фильтры |

Вход, выход, восстановление пароля и оформление остаются служебными функциями.
Для **admin** также открыт раздел **«Список пользователей»**: просмотр, поиск,
создание и редактирование аккаунтов, как в полной версии. Ссылка: `/?view=users`.
API `/api/users` допускает GET/POST/PATCH только после серверной проверки admin;
для base/plus/pro возвращает 403, без входа — 401.
Регистрация, проекты, второй контур, настройки проекта, DN, коллекторы,
спецификация, шкафы, 3D, диагностика отдельным инструментом, изменение
комплектующих закрыты.

## Сборка и локальный запуск на Windows

Команды выполняются из `E:\PumpStation_Calculator\frontend`.
Проверенная среда: Node.js 22.14.0 и Python 3.13. Зависимости фиксированы
в `package-lock.json`; для чистой установки используйте `npm ci`.

```powershell
npm run build:beta
npm run check
npm run preview:beta
```

Предпросмотр собранного Worker через Miniflare/workerd открывается по `http://localhost:3010/`.
Он слушает только `127.0.0.1`; **это локальная проверка, не сервер для интернета**.
Используйте `localhost`, чтобы браузер корректно работал с Secure cookie в
локальном контексте. Остановка — `Ctrl+C`.

Предпросмотр применяет SQL-миграции к отдельному каталогу
`.wrangler/beta-state`. Существующий `.wrangler/state` не используется.
Для другого порта или изолированной базы:

```powershell
node scripts/preview-beta.mjs --port 3010 --state-dir .wrangler/beta-state
```

По запросу владельца также проверен запуск на **3005** с существующей базой
разработки (1 пользователь, 9 проектов):

```powershell
node scripts/preview-beta.mjs --port 3005 --state-dir .wrangler/state --migrations skip
```

Это прямое подключение основной локальной базы, без копирования пользователей.
Для этой базы схема проверена заранее; миграции ранее применялись вручную,
поэтому повторный запуск миграций Wrangler пропускается явно. Перед первым
таким запуском сделан SQLite backup в `.wrangler/backups/before-beta-3005-*.sqlite`.
Проверка после запуска подтвердила сохранность записей пользователей и проектов.
Параметр `--migrations skip` не предназначен для новой пустой базы.

Настройки роли, URL или localStorage не переключают выпуск. Профиль
подставляется при сборке одновременно в клиент и Worker; неизвестное
значение останавливает сборку. Без настройки production-сборка выбирает beta,
а сервер разработки (`npm run dev`) — full.
Управляемый возврат полной версии: `npm run build:full` и развёртывание
полученного выпуска. После этого для beta снова нужен `npm run build:beta`.

Версия и профиль доступны в `dist/release.json` и `GET /api/release`.
При завершении beta-сборки удаляется только сгенерированная копия
`dist/client/model-assets`: 3D в этом профиле закрыт, а крупные локальные STL
превышают ограничение статических ресурсов Worker. Исходные
`public/model-assets` и ресурсы полной версии сохраняются.
Развёртывать можно только согласованную пару `dist/server` + `dist/client`.
Не раздавайте `dist/client` отдельным файловым сервером: проверку доступа
к данным выполняет Worker с `assets.run_worker_first: true`.

## Создание тестировщика

В существующей базе admin может добавить тестировщика через меню
**«Список пользователей» → «Добавить пользователя»**. Пароль задаётся
администратором; публичная регистрация остаётся закрытой.
Для первоначального заполнения отдельной базы доступна локальная команда ниже.

Один раз запустите предпросмотр для применения миграций и остановите его.
Затем выполните:

```powershell
python scripts/create-beta-user.py --email tester@company.ru --name "Имя Фамилия" --role base
npm run preview:beta
```

Пароль вводится дважды без отображения (10–256 символов). Команда создаёт
индивидуальную подтверждённую учётную запись с PBKDF2-SHA256, 310 000 итераций,
как в приложении. Общего пароля и встроенной учётной записи нет.
Повторный email приводит к отказу без изменения существующего пользователя.
До записи создаётся SQLite backup в `.wrangler/beta-backups`.

Для другого хранилища добавьте `--state-dir <путь>` одновременно в команды
создания пользователя и предпросмотра. Роли `plus`, `pro`, `admin` не снимают
ограничений расчётных инструментов beta. Управление пользователями доступно
только admin. Команда предназначена для **локального D1**, не удалённого.

Восстановление пароля использует существующую почтовую интеграцию. Для
реальных писем нужны `RESEND_API_KEY`, `EMAIL_FROM` и корректный `APP_BASE_URL`.
Локальная команда принимает первые два параметра из переменных окружения,
а `APP_BASE_URL` устанавливает в адрес своего localhost. Секреты не включайте
в исходники или общедоступные журналы. В beta ссылка сброса не возвращается
прямо в ответе API даже на localhost. Без настроенной почты выдаётся ошибка.
Доставка
на корпоративную почту должна быть проверена перед выдачей доступа сотрудникам.

## Состояние и защита данных

Параметры подбора и раскладка сохраняются в отдельном ключе браузера
`psc:beta:0.1:<userId>`. Читаются только разрешённые поля и окна; роли,
настройки проекта и запрещённые сущности из сохранённого объекта игнорируются.
Полные проекты не читаются и не перезаписываются. Несколько вкладок одного
пользователя синхронизируют beta-состояние через событие `storage`.

API закрытых модулей проверяет доступ до вычислений и изменений данных.
Без сессии возвращается 401; с любой ролью — 403 и
`FEATURE_DISABLED_IN_BETA`. Публичная регистрация возвращает 403.
Каталоги, чертежи и JS с внутренними данными требуют входа; неизвестные
файлы и данные закрытых модулей запрещены в beta. Ответы с внутренними
файлами имеют `Cache-Control: private, no-store`.

## Приёмка

1. Без входа открыть приложение, каталог `/pumps.json` и API проектов:
   форма входа без регистрации; прямые данные и API — 401.
2. Войти индивидуальной учётной записью. Проверить прежнее меню, ленту,
   окна и маркировку beta. Все закрытые инструменты видны и отключены.
3. Задать Q=20 м³/ч, H=40 м, статический напор=0, рабочих=1, резервных=0;
   выполнить подбор, выбрать насос. Проверить ту же модель в кривой и карточке.
4. Переключить метод кривой, экспортировать PNG/PDF, открыть чертёж/карточку.
   Проверить фильтры насосов, поиск и группы базы комплектующих.
5. В разделе «Вид» переключить свободные окна, сетку и Mobile; свернуть,
   восстановить, добавить и открыть инструмент отдельно. Перезагрузить страницу.
6. Открыть `/?panel=model`, `/?panel=input2`:
   открывается разрешённое рабочее пространство. Проверить 403 закрытых API
   для base, plus, pro, admin и невозможность записи в базу комплектующих.
7. Под admin открыть «Список пользователей» из меню и по `/?view=users`;
   проверить загрузку, поиск, возврат к окнам и перезагрузку страницы.
   У base/plus/pro пункта меню нет, ссылка возвращает в рабочее пространство,
   API пользователей возвращает 403; без входа — 401.
8. Выйти, повторно войти, остановить и запустить предпросмотр:
   учётная запись и beta-состояние сохраняются; полные проекты не меняются.

Автоматические проверки находятся в `tests/beta-release.test.mjs`.
Тест `tests/beta-http.test.mjs` запускает собранный Worker и проверяет
запрещённые методы, приватные файлы и вход/выход через настоящие HTTP-соединения.
План следующего этапа: [размещение на Windows-ПК](beta-0.1-windows-hosting.md).

- `npm run typecheck` и `npm run lint`: успешно.
- После открытия раздела пользователей для admin: `node --test tests/*.test.mjs`
  — 388 тестов, 0 ошибок, 0 пропусков. HTTP-тест проверяет доступ admin,
  отказы base/plus/pro и запросы без сессии; данные берутся из отдельной тестовой БД.
- `npm run build:beta`: успешно; финальный профиль в `dist/release.json` — beta.
  `npm run build:full` также проверен после выделения общих панелей интерфейса.
- Профиль beta проверен для base/plus/pro/admin; отрицательные проверки
  сохраняют исходные записи полных проектов без изменений.
- Раздел пользователей проверен в браузере на отдельной временной БД:
  переход из меню admin, загрузка списка, поиск, перезагрузка прямой ссылки,
  возврат в рабочее пространство и кнопка браузера «Назад». Для base пункт
  отсутствует, прямая ссылка возвращает в рабочее пространство.
- Перетаскивание и изменение размера используют локальный предпросмотр окна
  с обновлением по кадрам. Геометрия сохраняется после отпускания указателя;
  изменение раскладки не запускает заново подбор насосов. Окна за границами
  уменьшенного экрана больше не скачут внутрь при первом движении.
  Проверено в браузере на рассчитанной кривой Q=20/H=40: перемещение
  `(586,18) → (686,58)` полностью отменяется одним нажатием «Назад».
  После исправления прошли typecheck, ESLint и 32 профильных теста,
  включая новые проверки масштаба, границ, привязки и минимальных размеров.
- Свободные окна растягиваются за все четыре края и четыре угла.
  Противоположные края остаются на месте; действуют минимальные размеры,
  границы рабочей области и масштаб. Размер сохраняется при отпускании мыши.
  Список насосов занимает свободную высоту окна, сохраняя место минимум для
  трёх строк с учётом заголовка, переносов текста и полосы прокрутки.
  Проверены восемь направлений и отмена в браузере, восстановление размеров
  после перезагрузки; область списка выросла с 254 до 457 px по высоте.
  После доработки прошли typecheck, ESLint, сборка beta и 52 профильных теста.
- Цвет строк насосов и предупреждение о запасе напора используют общий порог:
  отрицательный запас — красный, от 0 до 15% включительно — зелёный без
  предупреждения, более 15% — жёлтый. Большой положительный запас не считается
  красной ошибкой. Проверены граничные значения в обоих контурах (27 тестов
  подбора и диагностики), typecheck, ESLint и сборка beta. В браузере проверены
