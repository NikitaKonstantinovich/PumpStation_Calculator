# Автозаполнение напорной линии

Кнопка «Добавить арматуру в спецификацию» заполняет обе гидравлические линии.
После заполнения состав обновляется при изменении насоса, патрубков, DN, PN,
материала, количества насосов, конфигурации коллектора и при загрузке проекта.
Напорные сборочные детали имеют `generatedBy: discharge-line`, раздел
`discharge` и нумерацию `04.xx`. Ручные позиции сохраняются; арматура заменяется
по существующему `option`, коллектор обновляет конструктор.

## Схемы и количества

Фланцевая ветка: напорный патрубок → ответная часть РФ, вставка ФФ или переход →
обратный клапан → отдельная вставка ФФ → затвор → отвод коллектора.
Вставка между арматурой имеет отдельную роль `primary-between-valves-insertion`
или `secondary-between-valves-insertion`: одна на каждый рабочий и резервный
насос своего контура. Два её фланца добавляются отдельно. Фланцы отводов и
концов коллектора уже входят в коллектор и повторно не добавляются.

При резьбовом патрубке и резьбовой арматуре DN арматуры равен DN патрубка,
как на всасывающей стороне. Между обратным клапаном и шаровым краном подбирается
латунный ниппель НР/НР. На ветку с американкой приходится пять резьбовых
соединений, с РФ со стороны фланцевого насоса — четыре. Расход льна —
0,1 м на соединение. Два сетевых подключения считаются один раз на коллектор.

## Каталоги и ограничения

Используется таблица `suction-catalog.ts`: вставки DN65–250, PN16.
Для PN25 и отсутствующих DN нет подстановки цены другого исполнения.
Материал тела вставки в исходной таблице не указан: её табличная цена
сохраняется, статус — «Уточнить», описание требует проверки материала и длины.
При явно указанном несовместимом материале цена не переносится.
Произвольная длина вставки не задаётся.

Уплотнения, фланцы, метизы и цены выбираются общими функциями
`line-spec-parts.ts`. Правила подбора прокладок, предупреждения при несовпадении
PN и стоимость льна сохранены.

Для каждого межфланцевого элемента рассчитывается отдельный пакет крепежа.
Исходные размеры берутся из `suction-fasteners.json`, экспортируемого из листа
«Полезная инфа» исходной книги: 017W — C75:C94, 010С — C123:C142,
толщина фланца 012F — D147:D166. Размеры из карточки выбранного изделия имеют
приоритет над справочником модели. Для неизвестной модели размеры не заимствуются.

017W крепится болтами с одной гайкой и шайбой. Для 010С учитываются шпильки,
две гайки, две шайбы и два выступа резьбы; для 012F — два фланцевых стыка.
Длина включает оба фланца, межфланцевый корпус, прокладки по 2 мм,
гайки, шайбы и выступы по 5 мм. Из базы берётся ближайшая доступная длина
не меньше расчётной. Если размеров или крепежа нет, позиция остаётся
«Уточнить». Толщины фланцев Ст20 не применяются к AISI304.

## Давление и приборы

Напор на выходе равен `station-settings.inletHead + system-input.head`;
для второго контура используется его `head`. `staticHead` не участвует.
Общие элементы и приборы подбираются по наибольшему напору активных контуров.
Отсутствующий напор не подменяется нулём.

Проверка хранится в `SpecItem.dischargePressureCheck` и отображается вместе
с действующими предупреждениями. Для насоса используется `maxPressure`
напорного патрубка. Манометры подбираются с существующим запасом шкалы 1,5,
реле — по диапазону давления напорной стороны; уставки задаются при наладке.
Отсутствующие исполнения сохраняют статус «Уточнить» и свои пояснения.

Проверки схем, количества вставок, крепежа, второго контура, отсутствующих
комплектующих, обновления и загрузки находятся в `tests/discharge-spec.test.mjs`.
