# Документация проекта

Актуализировано **29.10.2026** для текущего кода. Корень репозитория в рабочем
каталоге владельца — `E:\PumpStation_Calculator\frontend`; команды выполняются
из него. В чистом клоне используйте выбранную папку репозитория.

Инструкции описывают два профиля одного приложения: `full` для полной версии
и `beta` для ограниченного выпуска. Dev по умолчанию запускает `full`,
production-сборка без явного профиля — `beta`. Уровень доступа дополнительно
ограничивает операции; admin не снимает ограничения beta.

В текущую версию включены LEO XST, расчёт вставок и окраски, CSV/XLSX,
роли `base/plus/pro/admin`, миграции `0000`–`0010`, синхронизация спецификации
и 3D-сборки. Сравнение с базой `44b9f38` от 04.10.2026 сохранено только
в исторических отчётах; оно не описывает текущий checkout.

## Внешние материалы

Соседняя `database/` содержит SQLite для импорта, а рабочие пользователи и
проекты находятся в D1. `Equipment/` содержит исходные CAD/Excel/PDF.
`reference-calculator-nu/` — отдельный исходный проект; его FastAPI,
PostgreSQL, Stage-планы и AGENTS.md относятся к нему. Для данного приложения
действуют React/vinext, Workers/D1 и инструкции текущего репозитория.
