# Документация проекта

Сверено с кодом, каталогами и тестами 20.10.2026. Корень Git-репозитория —
`frontend` в исходном рабочем каталоге `PumpStation_Calculator`.
Все команды из инструкций выполняются из корня Git, если не указано иное.

## Версии инструкций

Опубликованная база приложения — `44b9f38` от 04.10.2026. Дополнения
локальной ветки `codex/component-calculator` ещё не закоммичены вместе с кодом.
Их документация сохранена с пометкой «Локальное расширение». Публикация
документов не добавляет описанные модули, данные и SQL-файлы в приложение.

| Область | Опубликованная база `44b9f38` | Локальная рабочая копия на 20.10.2026 |
| --- | --- | --- |
| Каталог насосов | 5 758 моделей, 4 978 для подбора, 53 452 точки Q/H | 5 856 моделей, 5 039 для подбора, 54 423 точки; добавлен LEO XST |
| Миграции D1 | `0000`–`0007` | `0000`–`0010` |
| Права | `user`, `admin` | `base`, `plus`, `pro`, `admin` |
| Локальные функции | — | Расчёт вставок, окраска Ст20, CSV/XLSX, новые правила сортировки и сборки с виброкомпенсаторами |

Для запуска чистого клона используйте инструкции опубликованной базы.
Применяйте только SQL, которые существуют в вашем checkout; наличие описания
миграции в документации не означает наличие файла. Исторические результаты
проверок действуют на указанную дату. Актуальное состояние данных определяется
по JSON и схеме соответствующей версии, а не по старому количеству тестов.

## Внешние материалы рабочего каталога

Соседняя папка `database` содержит прежнюю SQLite, её схему и отдельную
объединённую SQLite для импорта. Приложение использует `public/pumps.json`
для насосов и D1 для пользователей, проектов и серверных каталогов.
`database/pumps.sqlite` не является рабочей D1.

`reference-calculator-nu` — отдельный исходный репозиторий
`nickzon8/calculator-nu`, использованный при объединении данных. Его FastAPI,
PostgreSQL, Stage-документы, AGENTS.md и инструкции развёртывания относятся
к тому проекту. Для запуска этого приложения используются React/vinext,
Cloudflare Workers/D1 и инструкции текущего репозитория.
