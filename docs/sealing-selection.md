# Уплотнения и подбор прокладок

Источник дополнения: изображение таблицы пользователя от 28.09.2026. Данные сохранены в `data/sealing-supplement.json`: 22 исполнения прокладок и две строки льна для резьбы 2″ и 1½″. Пользователь подтвердил цену льна **51,5 ₽/м**.

Дополнение объединяется с `public/binding-components.json` при сборке. Оно сохраняется после повторного импорта исходной книги и не создаёт дубликаты при повторной сборке. Для одинакового DN, исполнения А, толщины 2 мм и группы давлений сохраняется прежний идентификатор и наибольшая цена. Исполнения на разные группы давлений не объединяются. Например, DN32 сохраняет 10,98 ₽, DN150 PN10/16 получает 87 ₽. В базе теперь 27 уплотнений: 25 прокладок и две строки льна.

В исходной книге у всех прокладок стоял PN10, а наименование формулой содержало «10–40». Для строк из дополнения группы совместимости уточнены по таблице пользователя и таблице 3 [ГОСТ 15180-86](https://www.zaar.ru/gosty/gost-15180-86.pdf):

- DN15–80: PN10/16/25/40.
- DN100/125/150: отдельные исполнения PN10/16 и PN25/40.
- DN200/250: отдельные исполнения PN10/16 и PN40. Прокладок PN25 в дополнении нет: у них другие наружные диаметры.
- DN300/350/400/500 из дополнения: только PN10.
- Существующие DN600/700/800 сохранены с исходным PN10 и ценами.

В спецификации всасывающей линии прокладки подбираются по точному DN и явному списку совместимых PN. Цена берётся из объединённой базы. Подбор охватывает соединения насосов, арматуры и коллектора с сетью, включая второй контур. Количества рассчитываются по существующим правилам соединений: одна прокладка у насоса, две у фланцевой арматуры, две на подключения общего коллектора к сети.

Если совместимого исполнения нет, выбирается прокладка того же DN с ближайшим большим PN. Если большего PN нет, выбирается ближайшее доступное PN. Такая позиция получает цену из базы, статус `confirmation` и жёлтое выделение с предупреждением о требуемом и выбранном PN. При меньшем PN отдельно отмечается недостаточное допустимое давление. Размеры и применимость замены требуют проверки. Если самого DN в базе нет, позиция остаётся на уточнение без цены.

Лён включается в стоимость спецификации по максимальной цене за метр из базы (сейчас 51,5 ₽/м). Две исходные строки по диаметрам описывают один расходный материал. Расход — 0,1 м на резьбовое соединение, с учётом числа насосов; для двух резьбовых подключений коллектора к сети — 0,2 м. Цены за упаковку для расчёта по метрам не используются. В полностью фланцевых соединениях лён не добавляется.

Изменение версии подбора обновляет ранее заполненную спецификацию, включая цену льна и предупреждения о заменах прокладок.
