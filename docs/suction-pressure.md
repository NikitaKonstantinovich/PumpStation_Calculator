# Проверка давления всасывающей линии

Источник напора — `station-settings.inletHead`. Давление в барах равно напору в метрах водяного столба × 0,0980665. `staticHead` относится к характеристике сети и в этой проверке не используется.

Проверяются выбранный PN общего коллектора, компоненты его состава и позиции всасывающей линии. Для комплектующих читаются явный PN и допустимое/максимальное рабочее давление с единицами бар или МПа. Требуемый PN из текста спецификации, совместимость размеров прокладки и диапазон измерения прибора не заменяют допустимое давление элемента. В составе коллектора используется PN компонента из каталога, включая восстановленные объединённые ячейки исходной таблицы.

Для насоса предусмотрено отдельное поле `maxInletPressure` в данных всасывающего патрубка (бар). Общее `maxPressure` не используется как предел давления на входе. Если отдельного параметра нет, выводится сообщение о недостатке данных.

Проверка имеет отдельные состояния: напор не задан, предел неизвестен, превышение, предел по указанному напору не превышен, неположительный напор. Отсутствующее значение не заменяется нулём. При нуле и разрежении предупреждения о превышении положительного PN нет; подбор приборов с учётом разрежения сохраняется.

Результаты записываются в `SpecItem.inletPressureCheck`; исходное описание, цена и статус сохраняются. Превышение или недостаток данных переводит позицию в `confirmation` — существующее жёлтое выделение. При повторной проверке снимается только предупреждение давления, остальные замечания остаются. PN автоматически не меняется. Выбор прокладок сохраняет порядок: подходящий PN, больший, ближайший с предупреждением.

Проверка обновляется при изменении напора, PN, состава и загрузке проекта. Она оценивает только давление по указанному напору; прочность, гидроудары и пригодность к работе под вакуумом не оцениваются.
