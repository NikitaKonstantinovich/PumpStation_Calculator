## Номинальная посадка DN250

Решение пользователя 31.10.2026: при равных номинальных диаметрах отверстия
и основы 273 мм принимать сборку без отдельной расточки, с примечанием
«фактическую посадку проверить при сборке». Применяется к AISI304 DN250
ряда 1 PN10/16/25. Это не утверждение нулевого фактического зазора.
Меньшее отверстие, другой DN/материал или явно заданный положительный зазор
по-прежнему требуют подтверждения расточки, размеров и тарифа.

Таблица 3 [ГОСТ 33259-2015](https://www.htpipe.com/d/files/flanges-standard/gost-33259-2015.pdf)
проверена визуально, PDF страница 33: отверстие 273 мм относится к ряду 1,
276,5 мм — к ряду 2. Размеры разных рядов не смешиваются.

## Сохранение

`import-insert-error-fixes.py` добавляет только четыре новых артикула одной
транзакцией с резервной копией. Повторный запуск не создаёт дубли; изменённые
пользователем записи не перезаписываются. Штатный `import-reducer-dimensions.py`
обновляет длины по ограниченному списку из 12 записей без изменения цен.

Оставшийся вопрос для DN400–300: подобрать фланцы под Ø406,4 мм каждого PN,
с подтверждёнными геометрией и ценой. Наличие фланца DN400 другого размерного
ряда не означает завершённый расчёт.
