# Промпт для проверки и исправления подбора крепежа

```text
Проверь и исправь подбор болтов, шпилек, гаек, шайб и прокладок для обвязки
насосной установки в проекте E:\PumpStation_Calculator. Проверь всасывающую
и напорную линии, основной и дополнительный контуры.

Принятый источник размеров и табличных длин — лист «Полезная инфа» книги
Equipment/Калькулятор по ОБВЯЗКЕ.xlsm. Таблицы прежнего калькулятора из
reference-calculator-nu не используй для подбора. В локальной распаковке имя
книги повреждено; найди файл в Equipment и проверь SHA-256:
f68b4519e1e6786982e026472d49553d70159e87154417c02f53b9ced3a1464c.
Если книга отличается, сначала повтори сверку и явно отрази различия.

Работай в актуальном состоянии проекта: в нём есть незакоммиченные изменения.
Изучи AGENTS.md, git status, фактический код и связанные тесты. Сохрани чужие
и несвязанные изменения. До правок составь краткую матрицу «источник → импорт
→ расчёт → строка спецификации» и список доказанных расхождений, затем внеси
необходимые изменения и проверь результат. Не ограничивайся отчётом об аудите.
Исходную Excel-книгу и рабочие базы данных не изменяй.

1. Прочитай значения и формулы листа «Полезная инфа»:
   - B51:E70 — количество отверстий по DN/PN;
   - G51:I70 — диаметр крепежа;
   - L51:N70 — толщина фланца из стали 20;
   - P51:R70 — табличная длина для соединения двух фланцев;
   - B75:H94 — затвор 017W: C — корпус, F/G/H — длины PN10/16/25;
   - B99:H118 — задвижка 47GV: D — фланец арматуры, F/G/H — длины;
   - B123:H142 — обратный клапан 10С: C — корпус, F/G/H — длины;
   - B147:H166 — клапан 012F: D — фланец арматуры, F/G/H — длины;
   - C193 — прокладка 2 мм; C195 — выступ резьбы 5 мм.
   Лист «Метизы» используй как зависимость формул и каталог ассортимента,
   размеров гаек/шайб и цен. Сверь документацию frontend/docs/valve-fasteners.md.

2. Проверь всю цепочку в frontend:
   scripts/export-suction-fasteners.py, scripts/import-binding-catalog.py,
   app/suction-fasteners.json, public/binding-components.json,
   app/line-spec-parts.ts, app/suction-spec.ts, app/discharge-spec.ts,
   app/specification-items.ts, app/collector-calculations.ts,
   app/collector-project.ts и соответствующие тесты.
   Сейчас импорт содержит размеры корпуса 017W/10С и фланца 012F, но не
   готовую таблицу всех длин крепежа. Поддержка шпилек с двумя гайками
   и шайбами уже есть — проверь её применение и не считай её отсутствующей.

3. Исправь выбор справочных данных и комплекта:
   - Используй точные DN, PN, материал, модель арматуры и тип соединения.
     Проверяй идентификацию модели по полям карточки; нормализуй обозначения
     10С/10C/010C и кириллические/латинские символы без случайных совпадений.
   - Для подтверждённых исполнений из книги используй соответствующую
     табличную длину конкретной модели и PN. Измерения другой модели,
     данные старого калькулятора и поля карточки, противоречащие принятому
     источнику, не должны молча переопределять эту длину.
   - 017W: один межфланцевый узел, n болтов, n гаек, n шайб.
     10С: один межфланцевый узел, n шпилек, 2n гаек, 2n шайб.
     012F/47GV: два самостоятельных фланцевых стыка, всего 2n болтов,
     2n гаек и 2n шайб; полная длина корпуса не входит в длину болта.
     Количество прокладок — две на изделие. Отрази, что кратность крепежа
     восстановлена из формул листа, а не из отдельной таблицы количества.
   - Различай пакет межфланцевого узла и отдельного фланцевого стыка.
     Не считай один стык дважды при добавлении ответных фланцев и вставок.
   - Количество узлов умножай на рабочие плюс резервные насосы каждого
     контура; общие соединения коллектора с сетью считай отдельно.
   - Выбирай нужный тип крепежа с точной резьбой и минимальной доступной
     длиной не меньше принятой требуемой. Гайки и шайбы подбирай того же
     номинального размера. Отличай требуемую длину от выбранной каталожной.
   - Нулевое или пустое значение в таблице не означает крепёж нулевой длины.
     Неизвестная модель, DN/PN вне таблицы, неподтверждённые размеры AISI304,
     отсутствие подходящего крепежа или конфликт источников должны оставлять
     явную позицию на уточнение. Не подставляй другое исполнение без указания.
   - В спецификации сохраняй источник, адрес ячейки, DN/PN, модель, тип
     соединения, требуемую и выбранную длины, количества и причину уточнения.
     Проверяй единицу цены: цена за штуку не должна заменяться ценой за кг.

4. Отдельно обработай доказанные ошибки исходных формул:
   - Диапазоны поиска гаек E108:G113 и шайб E129:G134 заканчиваются на М30;
     для М33/М36/М42/М45 формулы скрывают отсутствие результата через IFERROR.
   - Формула 017W пропускает две прокладки, формула 47GV — одну прокладку.
   - P51:R66 учитывает только один фланец, несмотря на заголовок «два фланца»;
     P67:R70 содержат записанные числа и требуют самостоятельной проверки.
   Сохраняй исходное значение листа отдельно от программного расчёта.
   Не выдавай известное ошибочное значение как проверенный комплект и не
   исправляй его молча. Для таких случаев показывай расхождение и статус
   уточнения. Вариант исправленного расчёта можно привести отдельно с явным
   объяснением; он не становится автоматически новым утверждённым правилом.
   Для 017W DN100/PN16 источник даёт 125 мм, текущая общая формула — 129 мм.
   Эту разницу нельзя скрыть одинаковым округлением до каталожного болта.
   Использование P:R для геометрии патрубков проверь отдельно; исправление
   подбора крепежа не должно незаметно менять длины и стоимость коллекторов.

5. Добавь проверки, сверенные с независимыми значениями листа:
   - Все 60 сочетаний DN/PN: отверстия, резьба, размеры и длины арматуры.
   - DN65/PN25: 8 отверстий, М16; 017W — 114 мм, 10С — 140 мм.
   - DN100/PN16: 8 отверстий, М16; 017W — 125 мм, 10С — 162 мм,
     012F — 68 мм, 47GV — 69 мм; отдельно проверяй расхождения формул.
   - DN200/PN16: 12 отверстий, М20.
   - Один узел 10С DN100/PN16: 8 шпилек, 16 гаек, 16 шайб.
   - Один 012F DN100/PN16: два стыка, 16 болтов, 16 гаек, 16 шайб.
   - DN500/PN25: М33; исходные 017W=236 мм и 10С=270 мм ошибочны.
     После восстановления размеров гайки/шайбы та же формула дала бы
     267 мм для 017W без прокладок и 332 мм для 10С; это диагностические
     значения, а не автоматически принятые размеры для закупки.
   - DN15–DN25 с нулевыми длинами, неподдерживаемые DN/PN, отсутствие модели,
     размеры другого исполнения, отсутствие гайки/шайбы/шпильки, AISI304,
     правильный тип крепежа, границы выбора длины и цена за штуку.
   - Независимые контуры, резервные насосы, отсутствие дублирования после
     повторного заполнения и сохранения/загрузки проекта, отсутствие устаревших
     позиций при смене DN/PN/материала/арматуры.

6. Запусти связанные тесты, production build и git diff --check. Если
   изменение затрагивает подбор арматуры или общую спецификацию, выполни
   относящуюся к ним регрессию. Обнови документацию по итоговой реализации.
   В финале укажи доказанные ошибки, внесённые изменения, точные результаты
   проверок и случаи, которые требуют уточнения инженерного правила.
```
