# Расчёт DN и проверка давления

Инструмент DN подбирает диаметры и исполнение обвязки. Ручные изменения DN, PN, материала и соединений в full доступны pro/admin; остальные роли используют автоматический подбор.

## DN и скорость

Рекомендация DN использует `v = (Q / 3600) / (π × (DN / 1000)² / 4)`. Q задаётся в м³/ч; в этой рекомендации DN используется как номинальный диаметр. Выбирается первый стандартный DN, укладывающийся в ограничение скорости. Если весь ряд исчерпан, выбранный максимальный DN ещё нужно проверить по диагностике.

Пределы скорости берутся из закреплённых базовых значений проекта. Резервное правило без этих настроек: до DN250 включительно — 2 м/с, выше — 3 м/с. Эти значения не следует приписывать всем проектам после публикации новых правил.

В расчёте коллектора фактическая скорость использует внутренний диаметр трубы: наружный диаметр минус две толщины стенки. Он не равен автоматически DN. Для ветви используется расход контура, делённый на число рабочих насосов.

## Соединения и материал

Резьбовое исполнение допускается до DN50 включительно для первого контура хоз-пит/SMART и для второго контура. Основной контур пожарной и совмещённой установки использует фланцы. DN резьбового патрубка может фиксировать DN резьбовой арматуры.

Для многоступенчатого насоса исходный DN арматуры учитывает патрубок. Фланцевую арматуру с DN меньше DN патрубка программа отмечает как ошибку. Если данные патрубка отсутствуют, их нужно уточнить.

Стандарт материала: Ст20 для пожарной установки, AISI304 для остальных типов. Фактическое сохранённое исполнение и ручные настройки имеют значение при расчёте.

## Давление

Всасывающая сторона проверяется по входному напору. Напорная — по сумме входного напора и заданного напора насоса; для общих элементов учитывается максимальное значение активных контуров. Статический напор в эту сумму не подставляется.

В реализации используется перевод `p, бар = H, м вод. ст. × 0,0980665`. Например, 10 м соответствуют 0,980665 бар в этой модели.

Возможны состояния: напор не задан, предел неизвестен, предел превышен, предел по указанному напору не превышен, напор неположительный. Пустое значение не равно нулю. Для входа насоса нужен отдельный допустимый входной предел; общий PN или диапазон измерения прибора его не заменяют.

Неположительный напор не подтверждает пригодность к вакууму. Проверка не оценивает прочность, гидроудар, закрытую подачу и все возможные режимы эксплуатации.

## Переключатель проверки

В full: вкладка «Расчёт» → «Проверка давления». По умолчанию включён; изменение требует pro/admin. Выключение убирает соответствующие сообщения, но не делает проверку пройденной и не подтверждает техническую готовность спецификации. DN, PN, цены и остальные проверки сохраняются.
