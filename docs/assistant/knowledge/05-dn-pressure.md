# Расчёт DN и проверка давления

Инструмент DN подбирает диаметры и исполнение обвязки. Ручные изменения DN, PN, материала и соединений в full доступны pro/admin; остальные роли используют автоматический подбор.

## DN и скорость

Рекомендация DN использует `v = (Q / 3600) / (π × (DN / 1000)² / 4)`. Q задаётся в м³/ч; в этой рекомендации DN используется как номинальный диаметр. Выбирается первый стандартный DN, укладывающийся в ограничение скорости. Если весь ряд исчерпан, выбранный максимальный DN ещё нужно проверить по диагностике.

Пределы скорости берутся из закреплённых базовых значений проекта. Резервное правило без этих настроек: до DN250 включительно — 2 м/с, выше — 3 м/с. Эти значения не следует приписывать всем проектам после публикации новых правил.

В расчёте коллектора фактическая скорость использует внутренний диаметр трубы: наружный диаметр минус две толщины стенки. Он не равен автоматически DN. Для ветви используется расход контура, делённый на число рабочих насосов.

## Соединения и материал

Резьбовое исполнение допускается до DN50 включительно для первого контура хоз-пит/SMART и для второго контура. Основной контур пожарной и совмещённой установки использует фланцы. DN резьбового патрубка может фиксировать DN резьбовой арматуры.

Для многоступенчатого насоса исходный DN арматуры учитывает патрубок. Фланцевую арматуру с DN меньше DN патрубка программа отмечает как ошибку. Если данные патрубка отсутствуют, их нужно уточнить.

В нодовом инструменте «Расчёт DN», если числовой DN отсутствует и выбран резьбовой тип патрубка, номинальный DN определяется по обозначению резьбы закреплённого каталога. Например, G1 соответствует DN25, G1 1/4 — DN32, G1 1/2 — DN40, G2 — DN50. Это действует для обоих патрубков и контуров. Под полем отображается «По резьбе … → DN…». Размер резьбы не является фактическим внутренним диаметром и сам по себе не подтверждает стандарт резьбы. Числовой DN каталога и явный ручной DN имеют приоритет. При переключении патрубка на фланцевое соединение определение по резьбе отключается; тип арматуры настраивается отдельно.

У вручную заведённого насоса DN, тип соединения и PN берутся из сохранённой
карточки отдельно для всасывающего и напорного патрубков в обоих контурах.
Повторно вводить их в расчёте DN не требуется. Ручные поправки в проекте
имеют приоритет; «Патрубок из каталога» возвращает текущие данные карточки.
Если заполнен только DN, программа показывает его и просит уточнить тип
соединения. Это также относится к ручным насосам, сохранённым ранее.

Стандарт материала: Ст20 для пожарной установки, AISI304 для остальных типов. Фактическое сохранённое исполнение и ручные настройки имеют значение при расчёте.

## Давление

Всасывающая сторона проверяется по входному напору. Напорная — по сумме входного напора и заданного напора насоса; для общих элементов учитывается максимальное значение активных контуров. Статический напор в эту сумму не подставляется.

В реализации используется перевод `p, бар = H, м вод. ст. × 0,0980665`. Например, 10 м соответствуют 0,980665 бар в этой модели.

Возможны состояния: напор не задан, предел неизвестен, предел превышен, предел по указанному напору не превышен, напор неположительный. Пустое значение не равно нулю. Для входа насоса нужен отдельный допустимый входной предел; общий PN или диапазон измерения прибора его не заменяют.

На всасе выбираются манометр и реле с наименьшим верхним пределом шкалы. На напоре при включённой проверке КИП подбирается по рабочему напору с входным подпором. При выключенной проверке берётся максимальный напор по исходным точкам подтверждённой кривой Q–H выбранного насоса. Для общего коллектора используется максимум активных контуров, для реле пожарной вставки — максимум своего контура. Подпор и количество параллельных насосов на этот напор не влияют. Если у учитываемого контура нет подтверждённой кривой, артикул и цена прибора остаются пустыми. Для преобразователя ONI порог выбора составляет 160 м включительно для 16 бар и свыше 160 м для 25 бар.

Неположительный напор не подтверждает пригодность к вакууму. Проверка не оценивает прочность, гидроудар и все возможные режимы эксплуатации. Отдельный расчёт PN КИП при закрытой подаче использует входной подпор и H(Q=0).

## Переключатель проверки

В полной версии переключатель «Проверка давления» расположен на вкладке «Расчёт». По умолчанию проверка включена. Изменение доступно ролям pro и admin. Выключение исключает проверку допустимого давления из диагностики, спецификации и выгрузки. Готовность оценивается по действующим проверкам. PN присоединения остаётся критерием совместимости деталей.
