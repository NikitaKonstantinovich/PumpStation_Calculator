# Базовые значения и версии проекта

Курсы, скидки и общие правила расчёта сохраняются в версиях. Публикация администратора не должна незаметно менять уже сохранённый расчёт пользователя.

## Разделы

Базовые значения включают курсы и скидки, межосевые расстояния, сварочные работы, скорости потока, окраску и предпочтительные комплектующие. Нарезка резьбы хранится внутри производственных/сварочных тарифов; настройки коллекторов — внутри предпочтений комплектующих.

Новый full-проект получает текущую опубликованную версию. Старый проект без версионного блока сохраняет прежние правила через legacy-версию. Индивидуальные курсы, скидки и ручные расстояния при таком переносе сохраняются.

## Как применить обновление

Уведомление о новой публикации открывает сравнение значений, единиц и влияния. Пользователь выбирает нужные разделы. Необновлённые разделы продолжают использовать свои версии. Ручные переопределения сохраняются, пока явно не разрешена их замена.

«Оставить значения проекта» закрывает сравнение, но не удаляет уведомление. После применения обновления затронутые расчёты пересчитываются либо требуют пересчёта. Проверьте спецификацию и диагностику.

В beta сохраняются ссылки на применённые версии, а сами значения загружаются с сервера. Новая публикация также не меняет цены существующего рабочего состояния автоматически.

## Почему у двух проектов разные результаты

Они могут использовать разные версии курсов, скидок, расстояний, скоростей, тарифов и предпочтений. Перед сравнением проверьте применённые разделы и ручные изменения. Цены из старого описания или примера нельзя считать текущими тарифами проекта.

Цена насоса с признаком уже учтённой скидки (`net`) не получает скидку повторно. Неизвестная цена работ не считается нулевой. Предпочтительное изделие применяется только при подтверждённой совместимости.

## Расстояния и настройки коллекторов

Новые правила расстояния привязаны к конкретным моделям. Шаг — от 400 мм через 50 мм, проверяемый зазор — не менее 150 мм при известных габаритах. Добавление новой серии в каталог не расширяет задним числом область старой публикации.

Pro и admin могут подтвердить ручное межосевое расстояние в конструкторе коллектора для собственного проекта. Это не публикует общее правило и не меняет базовые значения других пользователей. Применение новой версии раздела расстояний сохраняет ручное число, если не выбрана его замена, но требует нового подтверждения перед расчётом.

Сгоны коллектора задаются отдельно для восьми комбинаций: всас/напор × один/два контура × Ст20/AISI304. Сохранённая конфигурация проекта определяется применённой версией и не подменяется последним общим шаблоном.

Административный редактор доступен только admin. Обычному пользователю для обновления собственного проекта не нужен доступ к чужим черновикам или истории авторов публикаций.
