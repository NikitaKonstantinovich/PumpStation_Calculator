# Ошибки, предупреждения и устранение проблем

В full инструмент «Ошибки и предупреждения» собирает замечания по проекту, в том числе из закрытых окон. Сообщения обновляются при изменении исходных данных и активных контуров.

## Как перейти к проблеме

Красный знак обозначает ошибку, жёлтый — предупреждение. Фильтры ошибок и предупреждений независимы. Можно ограничить список одним инструментом или выбрать все.

Дважды нажмите на запись либо выделите её и нажмите Enter. Приложение откроет источник и выделит проблемное поле или строку. В спецификации подробности также доступны по знаку «!» рядом с наименованием.

## Частые ситуации

| Сообщение или симптом | Что проверить |
| --- | --- |
| Нет насосов в подборе | Q/H и единицы, статический напор, рабочее количество, среду и фильтры |
| Не найдено пересечение кривых | Исходную точку и доступный диапазон характеристики выбранного насоса |
| Напор на входе не задан | Поле входного напора; статический напор его не заменяет |
| Допустимое давление неизвестно | Предел конкретного изделия и именно нужного патрубка |
| Давление превышено | Требуемое давление и выбранное исполнение; скрытие проверки не устраняет превышение |
| Устаревший расчёт | Изменённые исходные данные/версию каталога; повторить расчёт и обновление |
| Неизвестна цена | Цену обязательной позиции и единицу измерения; не подставлять ноль |
| Спецификация — черновик | Отдельно состав, технические условия и полноту стоимости |
| Инструмент недоступен | Профиль full/beta и роль пользователя |
| Ошибка загрузки каталога или HTTP 503 | Доступность сервера и текст ошибки; при повторении передать администратору |
| Не строится 3D-деталь | Выбранное изделие, размеры, монтажные порты, подготовку CAD и её статус |

Устранение одной причины не подтверждает остальные проверки. Например, цена не подтверждает геометрию, а загруженный CAD не подтверждает допустимое давление.

## Данные для разбора конкретного проекта

Для объяснения нужны точный текст замечания, инструмент, профиль и роль, тип установки и активный контур. Для подбора дополнительно нужны Q/H, статический напор, количества и выбранная модель; для давления — входной напор и предел изделия; для соединения — DN/PN, материал и тип концов.

База знаний сама не видит открытый проект. Пока приложение не передало его параметры ассистенту, нельзя утверждать, что найдена причина именно в текущем расчёте. Следует запросить только недостающие значения, без паролей, ключей или данных чужих проектов.
