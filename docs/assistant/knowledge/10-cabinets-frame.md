# Шкаф управления и рама

Шкаф управления подбирается по типу установки, количеству и мощности насосов. Рама в текущей реализации получает конструкцию и высоту; полного расчёта её изготовления пока нет.

## Шкаф управления

Для хоз-пит применяется подбор BP, для пожарной установки — FP, при жокее — FPJ. Среди подходящих шкафов требуется совпадение количества насосов и достаточная мощность на насос; выбирается ближайшая не меньшая мощность.

Если точного номинала нет и выбран больший, сохраняется предупреждение. При неизвестной мощности насоса или отсутствии подходящего шкафа появляется позиция для уточнения с неизвестной ценой.

Для SMART проверяется диапазон мощности шкафа и число насосов. Мощность одного насоса для станции NS Smart ограничена 7,5 кВт. Если часть состава шкафа не имеет цены, частичная сумма не считается полной стоимостью.

Для совмещённой установки автоматический подбор шкафа не выполняется. Ручной выбор нужно проверять на соответствие обоим контурам. Подбор FPJ по основным насосам также не заменяет проверку мощности и количества жокей-насосов.

Ручной шкаф сохраняется после изменения конфигурации насосов, но требует повторного подтверждения применимости; его прежняя цена до подтверждения не считается актуальной.

## Правило выбора рамы

Используется масса одного насоса, а для нескольких активных контуров — самого тяжёлого отдельного насоса. Масса не умножается на количество рабочих или резервных насосов.

| Масса m, кг | Конструкция | Высота, мм |
| --- | --- | ---: |
| 0 < m < 50 | Гнутая рама, лист 4 мм | 50 |
| 50 ≤ m < 100 | Гнутая рама, лист 5 мм | 50 |
| 100 ≤ m < 300 | Швеллер 8П | 80 |
| 300 ≤ m < 500 | Швеллер 10П | 100 |
| 500 ≤ m < 1000 | Швеллер 12П | 120 |
| m ≥ 1000 | Швеллер 14П | 140 |

Точная граница относится к следующей группе: например, 100 кг — швеллер 8П. Насос легче 30 кг относится к первой группе. Это принятое правило приложения, а не расчёт несущей способности.

Если у хотя бы одного активного насоса неизвестна корректная масса, автоматический выбор конструкции отсутствует. Условная высота 80 мм в 3D при недостатке данных служит только просмотру.

Длина, ширина, отверстия, полный состав и стоимость рамы остаются незавершёнными. Поэтому строка рамы имеет неполный статус даже после выбора конструкции и высоты. По этой таблице нельзя выпускать производственный чертёж.
