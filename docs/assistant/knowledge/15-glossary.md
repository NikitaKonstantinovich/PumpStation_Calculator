# Термины и единицы калькулятора

| Обозначение | Значение в приложении |
| --- | --- |
| Q | Объёмный расход, м³/ч |
| H | Заданный напор насоса, м |
| Статический напор | Составляющая модели характеристики сети, м |
| Напор на входе | Исходное условие проверки давления всасывающей стороны, м |
| Рабочая точка | Пересечение характеристики насосов и системы |
| Рабочие насосы | Насосы, одновременно обеспечивающие расчётный расход |
| Резервные насосы | Установленные резервные единицы; увеличивают число ветвей, но не расчётный расход |
| DN / Ду | Номинальный размер; не равен автоматически измеренному внутреннему диаметру |
| PN / Ру | Обозначение номинального давления изделия; применимость требует данных конкретного исполнения |
| Ст20 | Обозначение материала стальных деталей в калькуляторе |
| AISI304 | Обозначение нержавеющего материала в калькуляторе |
| ШУ | Шкаф управления |
| КИП | Контрольно-измерительные приборы |
| НР / ВР | Наружная / внутренняя резьба |
| BOM | Вложенный состав деталей и работ узла |
| Ревизия | Версия сохранённого расчёта или редактируемого объекта |
| Базовые значения | Версионируемые общие правила и тарифы, закреплённые в проекте |
| Известная часть стоимости | Сумма подтверждённых актуальных цен при неполном составе или стоимости |

Геометрические размеры и координаты 3D обычно задаются в миллиметрах, масса — в килограммах, мощность насоса — в кВт, скорость — в м/с. Для цены обязательно учитывается единица: штука, метр, метр сварного шва или конец резьбы.

Перевод `бар = м вод. ст. × 0,0980665` относится к принятой модели давления в приложении. Диапазон шкалы манометра не является допустимым давлением всех деталей узла.

«Неизвестно», «не задано» и «ноль» — разные состояния. Пустая цена не означает бесплатное изделие; отсутствующий напор не означает нулевой напор. Термин «готово» в одном инструменте не подтверждает автоматически все условия станции.
