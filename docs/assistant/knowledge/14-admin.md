# Административные инструменты

Эта статья предназначена для admin. Роль и профиль приложения проверяются сервером; ссылки на страницы не предоставляют дополнительных прав.

## Пользователи

«Список пользователей» доступен администратору в full и beta. Можно искать, создавать и редактировать аккаунты. Перед записью интерфейс показывает изменяемые поля «Было / Станет».

Пароли не читаются из базы: администратор задаёт новый пароль. Пустое поле при редактировании сохраняет существующий. Смена почты, пароля или уровня завершает сессии изменяемого аккаунта. Изменение только имени сохраняет сессии. Самостоятельное понижение своего admin запрещено.

В full публичная регистрация создаёт base и требует подтверждения адреса. В beta публичная регистрация закрыта, аккаунты создаёт администратор. При конфликте версии обновите список и заново проверьте изменения.

## Публикация базовых значений

Откройте «Базовые значения» из меню. Редактирование и сохранение черновика не меняют действующие правила. Перед публикацией проверьте сравнение. Публикация создаёт неизменяемую версию; исправление оформляется новой публикацией.

Если другой администратор уже сохранил изменения, конфликт ревизии не следует обходить повторной записью старого состояния. Обновите данные и согласуйте изменения, сохранив нужные локальные правки.

Публикация не обновляет существующие проекты автоматически: пользователь применяет выбранные разделы через сравнение. Редактор базовых значений работает и в beta, сохраняя остальные ограничения выпуска.

## Калькулятор комплектующих

«Расчёт комплектующих» доступен admin в full. Он формирует и сохраняет изделия со своими параметрами, составом, размерами, ценой и ревизией. Сохранённые расчёты используются подбором вставок в станции.

После изменения источников, размеров или цен пересчитайте затронутое изделие. Сохранение должно учитывать текущую версию каталога. Наличие сохранённой записи не подтверждает снятие всех инженерных замечаний.

Покупные резьбовые патрубки уже включают нарезку. Тарифы отдельной нарезки задаются за один конец; цена «от» является нижней оценкой, а не подтверждённой ценой любого DN. Проверяйте вид цены, единицу и дату источника.

Вставки DN250 AISI304 с одинаковыми номинальными диаметрами отверстия и основы рассчитываются по принятому допущению: фактическую посадку проверить при сборке. Длины переходов DN300–150 (203 мм) и DN400–300 (356 мм) приняты пользователем по аналогам для конкретных записей; это не паспортное подтверждение стенок или давления. Фланец DN400 под Ø426 мм нельзя автоматически применять к переходу Ø406,4 мм.

## Сбои данных

При ошибках D1, недоступной таблице или сервисе CAD зафиксируйте действие и текст ошибки. Настройка сервера и миграции относятся к эксплуатационной документации. Не удаляйте рабочую базу и не запускайте повторно все миграции в качестве универсального способа исправления.

Эта база знаний не содержит пользователей, паролей, сессий, ключей API и содержимого рабочих проектов.
