кривой (88,32 м для этого насоса); при включённой — расчётное давление.
Проверены две канонические строки ONI с ценами, граница 160 м, автоматический
диапазон РД-2Р напорной вставки и размещение CAD на всех основных ветвях.
Предупреждения принятой схемы преобразователя и напорных реле удалены по
запросу пользователя. Диапазон измерения не переименовывается в паспортное PN.
KB-005 и KB-009 сверены с реализацией; правило всасывающего реле сохранено.
