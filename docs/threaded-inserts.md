# Резьбовые вставки: решения и источники, 30.10.2026

## Принятая конструкция

Решения пользователя 29–30.10.2026: готовые приварные резьбовые концы для СТ20 и AISI304; резьба не больше 2″; оба конца одного DN; компактная сборка без дополнительной трубы. Переходы с резьбовым концом не генерируются. Это не отменяет обычные концентрические и эксцентрические вставки.

Для резьба–резьба основой считается левый покупной патрубок, правый добавляется один раз: `L = Lлев + Lправ`. Для резьба–воротник `L = Lпатрубка + cворотника`. Для резьба–приварной фланец `L = Lпатрубка + 5 мм`: сохраняется принятое углубление торца на 5 мм от привалочной поверхности. Проверяются отверстие, толщина фланца и невозможность перекрытия всей длины патрубка. Дополнительная труба, правило длины по болтам 017W/010C и сварочный зазор здесь не применяются.

Патрубок входит в состав как готовая штука. Между двумя деталями одна сварочная операция по принятой норме `2πDнаружный`; свободный фланец за воротником остаётся вспомогательной деталью 3D, без добавки к стоимости/длине. Для СТ20 окрашивается суммарная длина покупных патрубков по действующему тарифу DN. Нарезка уже включена в покупную деталь и отдельно не начисляется.

Детали PN16 допускаются в готовых вставках PN10 и PN16. Исключение PN25 для сгона датчика на основные резьбовые концы не распространяется. Цена, PN и геометрия сохраняются сервером; изменение источников требует пересчёта.

Размеры AISI304: [технический паспорт NEWKEY NK-NE](https://cdn.vseinstrumenti.ru/instruction/nomenclaturecontent/202512/57887258.pdf/20807990_other.pdf), стенка `(D−D1)/2`. Цены и PN: карточки NEWKEY, точные ссылки для каждого артикула в `data/thread-ends.json`. Сегмент `pn63` старых URL не является характеристикой: карточки и паспорт указывают PN16. Паспортные диаметры 42/48/60 мм не заменяются автоматически на ISO 42,4/48,3/60,3 мм.

Цены проверены 30.10.2026, остаются справочными предложениями поставщиков. Дата наблюдения хранится отдельно от даты страницы (на сайте встречается будущая дата).

## Тарифы нарезки

В «Базовые значения → Нарезка резьбы» добавлены 12 редактируемых ставок, единица — один конец. СТ20 DN15/20/25/32/40/50: 85/100/115/125/135/170 ₽ по [прайсу «Металл ДК»](https://dedovsk.metall-dk.ru/service/narezka-rezby/), длина резьбы 10–50 мм. Для AISI304 во всех шести DN сохранён общий минимум **от 600 ₽/конец**, по [TOPM](https://topm.pro/narezanie-rezby); это не шесть подтверждённых индивидуальных расценок. Источники, дата, условия и вид цены видны в таблице. Окончательную стоимость, НДС и объём партии уточняют у исполнителя.

Тарифы опубликованы новой версией раздела сварочных/производственных работ. Старые публикации и применённые тарифы проектов неизменны; пользовательские правки черновика сохранены. Старым версиям тарифы автоматически не подмешиваются. Покупные патрубки эти ставки не потребляют.

## 3D и существующая библиотека

Проверены `Equipment/Piping/3D/Элементы трубопроводов/Резьба стальная` и `…/Сгоны`. В библиотеке есть SLDPRT для DN15–50. По нативной геометрии обнаружено: у стальных DN15/DN20 с именем L=30 фактическая длина 38 мм; DN32 L38 имеет D42,3/s3,2; DN40 L40 — D48/s3,2; DN50 L45 — D60/s3,5. Последние два отличаются от выбранных товаров стенкой/длиной. Нержавеющие DN32 L30 имеют D41,91/s3, DN40 L50 — D48/s3, DN50 L50 — D60,3/s3. Файл DN25 имеет зеркальный вариант с несколькими телами. Совпадение DN не доказывает совпадение изделия.

Чертёж `Equipment/FabricatedParts/3D/Переходы с фланца на резьбу/Переход DN50 - 2 PN16 AISI304.pdf` подтверждает компоновку 38+23=61 мм для показанных в нём деталей. Это отдельное исполнение, не размер покупного NEWKEY L50.

Шаблон строится по размерам конкретного артикула: два физических элемента, один стык, без дублирующего левого патрубка и выдуманной трубы. Резьба показана как компоновочный цилиндр, без винтовой поверхности. Точки подключения — свободные торцы, с DN, PN, размером резьбы и НР. Они предварительные для навинчивания: глубина сопряжения с ответной деталью не подтверждена. Непроверенные SLDPRT и латунные STEP Valtec не назначаются точными моделями стальных/нержавеющих товаров.

## Остаточные ограничения рабочей базы

Проверка без сгона датчика: 36 компактных исполнений PN10/16, 22 с полным расчётом, 14 неполных. Это отдельный аудит резьбовых вставок, не всех переходных изделий.

* AISI304 DN32/40/50 PN10/16, резьба–воротник: паспортные D патрубка 42/48/60 мм отличаются от воротников 42,4/48,3/60,3 мм; требуется согласование реального стыка или подходящие патрубки. Номинальный DN не снимает проверку.
* СТ20 DN32/40/50 PN10/16, резьба–фланец: отверстия исходных фланцев меньше патрубков. Нужны подходящий готовый фланец либо посадочный зазор и тариф расточки. Позиции `фланцы-001-r0007…r0009` (PN10), `фланцы-002-r0030…r0032` (PN16).
* СТ20 DN50 PN10/16: не подтверждена цена `thread-end:dnru-d270-18288`; это блокирует оба типа концов.

Для исходного каталога использованы добавляющие импортеры с резервной копией SQLite; повторный импорт не создаёт дубли и не перезаписывает изменённые пользователем записи. Расчёт, права admin, повторная выгрузка, обновление цены, устаревший результат, состав и точки 3D проверяются тестами.
