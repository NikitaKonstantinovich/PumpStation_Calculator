# Фланец DN150 для вставок PN25 — 26.10.2026

На снимках пользователя неполными оставались концентрические вставки
DN150–80, DN150–100 и DN150–125 AISI304 PN25. Общая причина — исходный
левый фланец `фланцы-007-r0143`: отверстие 161 мм меньше наружного диаметра
перехода 168,3 мм. Зазор и тариф расточки не заданы. Данные этой позиции
сохранены: толщина 30 мм, цена 9 290,96 ₽.

В базу добавлен готовый аналог по ранее принятому для серии Newkey подходу.
Недостающие размеры получены из таблиц заявленного DIN2503, с явным
указанием основания. Паспорт конкретного артикула не найден; размеры
не являются обмером поставленной партии.

| Атрибут | Значение |
| --- | --- |
| Артикул / ID базы | NK-FDh150/4 / 1834 |
| ID исходного каталога | `newkey-din2503:NK-FDh150-4` |
| Материал | AISI304 (CF8), по данным производителя |
| DN / PN детали | 150 / 40 |
| Принятые PN применения | 25, 40, для этого артикула |
| Наружный диаметр трубы / отверстие | 168,3 / 170,5 мм |
| Полная толщина плоского диска | 28 мм |
| Наружный диаметр / окружность крепежа | 300 / 250 мм |
| Сверловка | 8 × 26 мм |
| Цена | 9 487 ₽/шт., опубликованная розничная цена |

Источники проверены 26.10.2026:

- [Newkey, серия DIN2503](https://www.newkey.ru/catalog/flantsy/flantsy-ploskie-din2503/):
  артикул, DN150, AISI304 (CF8), PN40, труба 168,3 мм и цена.
- Изготовитель Hyupshin: [PN40](https://www.hsflanges.com/DIN_2503_PN40_plate_flanges)
  и [PN25](https://www.hsflanges.com/DIN_2503_PN25_plate_flanges.html).
  Для DN150 совпадают отверстие, толщина, наружный диаметр и сверловка.
- Изготовитель [Tesco](https://www.tescoflanges.com/din-2503-pn-40-slip-on-flange):
  независимая сверка размеров и присоединительной геометрии PN25/PN40.

НДС, доставка и персональная скидка не пересчитываются. PN покупной
детали остаётся 40, PN готовой вставки — 25. Совместимость не переносится
на другие DN или произвольные фланцы PN40. Основания записаны в
`geometryBasis`, `pressureSource` и отдельных атрибутах `CALC_FLANGE_*`.
Факты и ссылки сохранены в `data/sources/newkey-dn150-20261026/verified-facts.json`.

## Результат расчёта

Все три концентрические вставки без сгона теперь полные:

| Вставка AISI304 PN25 | Основа / общая длина, мм | Правый фланец | Цена, ₽ |
| --- | --- | --- | --- |
| DN150–80 | 140 / 150 | Исходный `фланцы-007-r0140` | 29 648,31 |
| DN150–100 | 140 / 150 | `ifitting-en01:1154` | 36 445,14 |
| DN150–125 | 140 / 150 | `newkey-din2503:NK-FDh125-4` | 36 248,11 |

Слева используется Newkey DN150. Отступы торцов — по 5 мм, глубина
посадки слева 23 мм, справа соответственно 21, 24 и 21 мм. Дополнительной
трубы и расточки нет. Две сварочные операции считаются по фактическим
наружным диаметрам: `2π × (168,3 + Dменьшего конца)`, тариф AISI304 —
5 000 ₽/м. Эксцентрические исполнения также рассчитываются. Со сгоном
DN15 сохраняется ранее принятое предупреждение PN25.

Правило выбора концов коллекторов остаётся действующим: AISI304 DN150
PN10/PN16 использует воротники. Готовый аналог участвует в отборе только
для разрешённого фланцевого исполнения; подходящие исходные детали
имеют приоритет. Кандидаты со старым отверстием 161 мм по-прежнему
неполные, их ограничения не скрыты.

## База и контроль

Добавлена одна запись. Проверено сохранение всех существовавших строк,
атрибутов, цен и связей. Ревизия 5647 → 5671, повторный импорт не меняет
ревизию и не создаёт дубль. `quick_check=ok`, внешние ключи без ошибок.
Резервная копия и результат: `work/newkey150-db-import.json`;
повторная проверка: `work/newkey150-db-repeat.json`.

Для DN15–800, обоих материалов и обоих типов переходов осталось
477 вариантов. В каждом сценарии (без сгона, со сгоном, с явной стыковой
посадкой воротников) полными стали ещё 9 строк. Все 464 строки вне
DN150 PN25 сохранили цену, размеры, состав, швы и решения посадки;
ранее полные расчёты не стали неполными. Сравнение:
`work/newkey150-comparison.json`.

Алгоритм остаётся 29; изменение каталога и ревизии базы требует нового
расчёта перед выгрузкой. Готовые вставки сохраняются отдельной кнопкой
«Выгрузить». Новые тесты проверяют три размера, оба исполнения переходов,
сгон, отсутствие лишней трубы и расточки, стоимость, швы, блокировку при
недостающих исходных данных, серверное сохранение и повторную выгрузку.
