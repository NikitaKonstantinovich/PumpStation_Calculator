# 3D-модели ONIS MV и MH

Импорт от 31.10.2026 использует папки `MV1`…`MV90` и `MH1`…`MH10`
из пользовательских загрузок. Исходники копируются без изменения содержимого:

В поставке 258 файлов: 235 STEP успешно подготовлены, 23 DWG сохранены как
исходники. 208 STEP-моделей связаны с каталогом, 27 доступны для ручного
размещения без назначения чужих характеристик.

- `Equipment/Pumps/3D/vertical_multistage/ONIS/MV/<группа>/`;
- `Equipment/Pumps/3D/horizontal_multistage/ONIS/MH/<группа>/`.

Исходные папки Downloads остаются на месте. SHA-256 исходников записан в
`data/onis-model-import.json`. Файлы DWG серии MV45 сохранены, но существующий
STEP/OCP-конвертер их не преобразует: для отображения требуются объёмные STEP/STP.

Подготовленные STEP-копии находятся в `Equipment/Pumps/3D_ONIS_Normalized/`.
Нормализация добавляет жёсткое преобразование сборки, сохраняя исходные определения
геометрии. Масштаб всегда 1:1, единицы — миллиметры, вертикаль — Z.
Повторное чтение подготовленного STEP проверяет преобразованные габариты.
Сетки STL и общие индексы располагаются в `public/model-assets/`.
Сообщения конвертера о пропущенных поверхностях без триангуляции сохраняются
в предупреждениях профиля. Такие сетки требуют визуальной сверки с исходником.

## Использование

Выберите насос ONIS в проекте, откройте «3D модель» → «3D редактор» и нажмите
«Обновить состав». Для точно совпавшего обозначения насос получает готовую CAD-сетку.
Изменения компоновки обрабатывает штатное обновление редактора.
Через «Из библиотеки» можно найти модели по `ONIS`, `MV1-10`, `MH 1-3` и другим
обозначениям, включая исполнения, которых нет в расчётном каталоге.

Привязка выполняется только по точному обозначению ONIS. Например, `MV32-10`
не заменяет `MV32-10-2`. Для файлов MH дополнительно проверяется напряжение 380 В.
Импорт не создаёт расчётные характеристики, цены и позиции спецификации.

## Монтажные ограничения

Патрубки измеряются по кольцевым торцевым поверхностям исходного STEP.
Для MH осевое отверстие назначено входом, радиальное — выходом вверх.
Точки предварительные: фактическое резьбовое зацепление не моделируется.

Для MV импорт измеряет соосные торцы PORT_A и PORT_B. Редактор назначает им
роли входа и выхода, если направление для конкретного STEP подтверждено в аудите ниже.

Габариты берутся из CAD. Если они расходятся с известными габаритами каталога,
профиль содержит предупреждение с обоими значениями. Модель не растягивается
под таблицу. Совпадение обозначения не подтверждает комплектацию двигателя,
материал и монтажную пригодность. Сверловка и опорные плоскости крепежа
проверяются по модели соответствующего насоса.

## Повторная подготовка

Из `frontend`, используя Python с `cadquery-ocp`:

```powershell
E:\PumpStation_Calculator\work\3d-audit\.venv\Scripts\python.exe scripts/import-onis-models.py --downloads C:/Users/N1kit/Downloads --run --workers 4
```

Без `--run` создаётся только опись. Копии с несовпадающим хешем не перезаписываются.
Подготовка выполняется отдельными процессами с тайм-аутом; повторный запуск
использует проверенные по хешам результаты из `.model-library/onis-2026-10-31/`.
Ошибка одного STEP не останавливает другие задания и отражается в отчёте.
Точные ссылки насосов находятся в `data/onis-model-registry.json`; этот реестр
также читает сервис подготовки моделей по кнопке в приложении.
Если сервис уже работал до обновления скриптов, перезапустите его для загрузки
нового пути реестра. Готовые локальные STL доступны редактору без конвертации.

```powershell
python -m unittest discover -s tests -p test_onis_models.py -v
node --test tests/onis-models.test.mjs
# Полная локальная проверка исходников и всех STL (крупные CAD-файлы вне Git):
$env:PSC_TEST_CAD_FILES='1'
node --test tests/onis-models.test.mjs
```
## Проверка всех ONIS от 02.11.2026

Проверены 811 расчётных позиций и 258 файлов поставки. У всех 235 нормализованных STEP сверены исходные файлы, SHA-256, целостность STL и координаты обеих кольцевых торцевых поверхностей. У 29 MH подтверждены осевой вход и верхний радиальный выход. У 10 MV20 подтверждены две стрелки на противоположных лапах одного корпуса и измерена сверловка обоих фланцев. Среди этих десяти MV20-14 доступен в библиотеке для ручного добавления. У остальных 196 STEP серии MV (170 каталожных и 26 библиотечных) назначение сторон остаётся неподтверждённым. Все 23 DWG серии MV45 прочитаны в LibreDWG 0.14. В них имеются чертёжные объекты, объёмных тел и прокси-объектов не обнаружено.

У MV20-3 обе стрелки идут вдоль +X. Патрубок A в точке (0, 0, 0) — всасывающий, B в точке (300, 0, 0) — напорный, координаты в миллиметрах. На каждом фланце четыре отверстия Ø18 мм на окружности Ø125 мм. Результат привязан к SHA-256 STEP и системе координат. [Проверенные привязки](../data/onis-flow-reviews.json) · [Скрипт проверки](../scripts/audit-onis-models.py).

На контрольном стыке редактора проверены все 811 каталожных позиций. У 38 насосов направление присоединения задано по CAD, 170 ждут подтверждения направления. Для 293 позиций доступны монтажные координаты из каталога, ещё для 310 строятся условные точки. У погружных насосов проверяется только напорный выход. Подбор конкретных клапанов и крепежа зависит от спецификации проекта.

Редактор применяет результат и к проектам с прежней версией библиотеки, если совпадают исходник и обе точки. Для сохранённой станции с разложенной рядом арматурой нажмите «Добавить обвязку» в инструменте «3D-модель». При отсутствии подтверждённого направления редактор показывает причину рядом со сценой.

В копии PS-2026-UF7LWX четыре ветви двух MV20-3 замкнулись от патрубков насосов до коллекторов. Максимальный зазор расчётных стыков меньше 0,001 мм. В проверенном ZIP задействованы оба насоса, четыре затвора и два обратных клапана. Из 81 позиции в файл вошли 58. Отчёт задания перечисляет 12 фланцев, шесть групп крепежа, четыре сгона и раму с неподтверждённой геометрией. [Проверка по каждому насосу и файлу](../../outputs/ONIS/Проверка-3D-ONIS.csv).
