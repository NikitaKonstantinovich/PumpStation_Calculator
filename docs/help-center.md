# Центр помощи

Откройте боковое меню и нажмите «Центр помощи» в нижней части. Вкладки «Документация» и «Поддержка» доступны всем вошедшим пользователям: base, plus, pro и admin, в full и beta.

## Документация

Материалы сгруппированы по началу работы, расчёту станции, 3D, настройкам и доступу, исходным размерам, эксплуатации, истории и планам. Поиск работает по названию и полному тексту. Фильтр раздела можно совмещать с поиском.

Краткие руководства дополняются подробными документами проекта. Исторические аудиты и планы помечены отдельно: они не являются безусловным описанием текущего поведения программы.

Статья открывается внутри приложения. Поддерживаются таблицы, списки, код, внешние ссылки и переходы между документами. Прямую ссылку из адресной строки можно сохранить; кнопки браузера «Назад» и «Вперёд» работают с открытым документом и вкладкой. Отсутствующий документ показывает сообщение и возможность вернуться к списку.

Читать описание административных инструментов можно с любой ролью. Выполнять административные действия по-прежнему может только уполномоченный пользователь. Документация не включает инструменты full в beta.

## Сопровождение

`scripts/build-help-content.mjs` собирает текст из `docs/*.md`, 16 статей `docs/assistant/knowledge/`, README приложения и двух описаний каталога насосов. Он входит в prebuild. После изменения Markdown при работающем dev-сервере запустите сборщик отдельно. Производный файл — `app/help-documents.json`; его не редактируют вручную.

Служебные инструкции AI, env-файлы, проекты и базы пользователей в комплект не входят. API `/api/help` проверяет авторизацию; содержание статей загружается по ID. Поисковые результаты содержат краткие выдержки, полный текст передаётся только для открытого документа. Общий доступ к чтению не расширяет права остальных API.

Проверки: `node --test tests/help-center.test.mjs`, `node scripts/build-help-content.mjs --check`, TypeScript и сборки обоих профилей. HTTP-проверки beta отдельно проверяют чтение справки с разными ролями.
