# Размерные чертежи в нодовых карточках

Оба контура получают файлы из закреплённого снимка `pump_catalog_v2`. Реестр `data/pump-drawings-reviewed.json` задаёт явные привязки к ID исполнения, модели, артикулу, названию и параметрам двигателя. При изменении этих данных привязка не применяется. Общие листы каталога помечаются как справочные; файлы соседней модели автоматически не подставляются.

Исходники и PNG страниц PDF лежат рядом с канонической SQLite-базой в `drawing-files/`. Имена имеют вид `<sha256>.<extension>`. При переносе локальной установки нужно переносить этот каталог вместе с базой и реестром. Старые файлы сохраняются для проектов со старыми снимками. Эндпоинт `/api/pumps/catalog-drawings/[id]` требует входа, разрешает только известные форматы и передаёт запрос зарегистрированному сервису `NODE_CATALOG`; сервис проверяет путь и SHA-256 файла. Облачному развёртыванию нужен соответствующий обработчик `/files/` в этом сервисе.

Карточка показывает PNG оригинального чертежа либо растровый предпросмотр указанной страницы PDF, сохраняет доступ к оригиналу, номер страницы и область применимости. Есть кнопки масштаба и Ctrl + колесо. Размеры по пикселям не вычисляются. Связи расчётов, межосевые расстояния и параметры насосов не изменяются.

Аудит и воспроизводимые скрипты подготовки: `outputs/pump-card-drawings-2026-11-09/` в корне основного репозитория. `drawing-audit.json` содержит происхождение каждого выбранного файла, контрольные суммы, пропуски и отклонённые повреждённые файлы; `report.json` — проверку всех карточек и выдачи файлов. После обновления реестра нужно создать новый снимок каталога. Старые снимки и закреплённые версии проектов не переписываются.

Чтобы использовать новые файлы: в Geometry Nodes нажать «Обновить снимок каталога», в рабочем пространстве 2 — «Применить актуальную версию продукта» и сохранить проект. Раздел «Чертёж и документы» должен быть включён в свойствах ноды карточки.
