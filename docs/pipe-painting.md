# Окраска труб и вставок Ст20

**Локальное расширение, сверено 20.10.2026.** Код, тарифы и скрипты из этой
инструкции отсутствуют в опубликованной базе `44b9f38`. Они доступны
в рабочей копии `codex/component-calculator`; см. [версии инструкций](README.md).

Источник: пользовательский файл `Прайс_окраска_труб_до_400.xlsx`, лист
«Прайс окраски труб», A5:B31. Все 27 исходных цен за погонный метр и SHA256
сохранены в `data/pipe-painting-prices.json`. Используются значения столбца B,
а не неокруглённые опорные цены из примечания A2. НДС в файле не указан;
дополнительное изменение налогов не применяется.

В базе: **Работы и услуги → Работы → Окраска труб Ст20 по DN**.
Одна позиция на DN независимо от PN и толщины стенки, всего 20 для DN15–800.
DN сопоставляется с наружным диаметром трубы именно из каталога Ст20.
Малые размеры прайса 26,8 / 33,5 / 42,3 / 48 мм сопоставлены DN20 / 25 / 32 / 40,
которые в каталоге имеют 26,9 / 33,7 / 42,4 / 48,3 мм. Это явные сопоставления
по DN в исходном JSON, без автоматического поиска ближайшего диаметра.
При двух разных наружных диаметрах одного DN импорт прекращается с ошибкой.

Известные тарифы сохраняются без наценки. Отсутствующие диаметры рассчитываются
линейно по двум ближайшим точкам исходного прайса и получают запас 15%.
Внутри диапазона это интерполяция, снаружи — экстраполяция. Расчётные точки
никогда не используются как опорные. Результат округляется до 0,01 ₽/м.
Для текущих пяти недостающих размеров используются Ø377 = 5750 ₽/м и
Ø400 = 6300 ₽/м:

`P(D) = (5750 + (D − 377) × (6300 − 5750) / (400 − 377)) × 1,15`.

| DN | Наружный диаметр, мм | Тариф с запасом, ₽/м |
| --- | ---: | ---: |
| 400 | 426 | 7960 |
| 500 | 530 | 10820 |
| 600 | 630 | 13570 |
| 700 | 720 | 16045 |
| 800 | 820 | 18795 |

Вставки Ст20 автоматически получают отдельную строку состава:
`Стоимость окраски = Lосновы, мм / 1000 × тариф DNбольшего`.
Для прямой вставки используется длина трубы; для концентрического и
эксцентрического перехода — каталожная осевая длина перехода и тариф большего DN.
Осевые добавки концевых деталей, фланцы и сгон не образуют дополнительную длину
окраски трубы. AISI304 не получает окраску. Цена вставки — детали + сварка + окраска.
Например, DN100 PN16 Ст20: труба 223,5 мм × 800 ₽/м = 178,80 ₽ окраски.

В составе сохраняются количество, единица, действующий тариф, стоимость,
ссылка на позицию базы, исходные ячейки, сопоставление DN и формула с запасом.
Отсутствующий, неоднозначный или некорректный тариф делает расчёт неполным.
Изменение цены в D1 аннулирует предыдущий результат; запись требует нового
серверного расчёта. Окраска не меняет физический ключ вставки, геометрию и швы.
Сохранённые ранее вставки обновляются штатной кнопкой «Выгрузить» после расчёта.

Конструктор коллекторов Ст20 использует эту же базу тарифов. Он складывает
окраску основной трубы и патрубков всех активных контуров: каждый участок
считается по собственному DN и суммарной длине, включая резервные насосы.
Подробнее — в [методике конструктора коллекторов](collector-constructor.md).

## Обновление данных

`scripts/build-collector-catalog.mjs` добавляет тарифы в публичный каталог,
а `scripts/build-component-insert-source.mjs` включает их в серверный резервный
источник. Рабочая база D1 остаётся основным источником при наличии импорта.

```powershell
node --experimental-strip-types scripts/build-collector-catalog.mjs
node scripts/build-component-insert-source.mjs
node scripts/import-pipe-painting.mjs --database "C:\path\to\local-D1.sqlite"
```

Перед импортом остановите локальный сервер и замените путь в примере на
существующий файл вашей локальной D1. Импорт берёт DN/наружные диаметры из активной базы, создаёт резервную копию
SQLite, затем атомарно обновляет только семейство `pipe-painting-st20-v1`.
Повторный импорт тех же цен не создаёт дубли и не изменяет ревизию источника.
Остальные комплектующие, их цены и пользовательские проекты сохраняются.
