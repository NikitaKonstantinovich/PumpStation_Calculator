## Результат и правила

- 5 758 моделей: Aquastrong 1 389, CNP 1 095, ONIS 811, VANDJORD 1 421, Wellmix 1 042.
- Все 1 683 модели прежнего каталога сохранены с прежними ID; 1 275 сопоставлены с источником.
- Ключ сопоставления: производитель + модель без пробелов, с нормализацией `CHLF(T)` → `CHLF` и десятичной запятой → точкой. Суффиксы исполнений не отбрасываются; `ECH(M)` и `ECH` не смешиваются.
- Заполненное значение источника имеет приоритет. Пустые поля, `null` и обозначения `—` не стирают старые сведения. Словари характеристик дополняются по полям. Предыдущие значения доступны в `conflicts.json` и `records.json`.
- Приоритет внутри нового источника: SQLite → специализированные каталоги чистой воды → точные прайс/технические данные CNP FSWPC. Мощность двигателя CNP берётся из моторных исполнений, а не из гидравлической кривой мощности.
- Исходные артикулы, материалы, размеры, электрические характеристики, документы, дополнительные кривые и варианты исполнений сохраняются в `records.json`. Данные старой SQLite также сохранены по прежним ID. Метаданные исходных JSON, включая ограничения готовности источника, находятся в `source-metadata.json`.
- 53 452 точки Q/H; расход нормализован в м³/ч, напор — в метрах. Подбор использует PCHIP без экстраполяции. График поддерживает PCHIP (по умолчанию), ломаную и полиномиальное сглаживание; пересечение с характеристикой системы и экспорт используют выбранный способ. Смена способа в графике не меняет метод подбора. Полином может отклоняться от исходных точек и недоступен, если даёт отрицательный напор внутри диапазона. Параллельные насосы увеличивают расход, не напор.
- Разделены чистая вода и сточные воды. Для подбора доступны 4 978 моделей. 780 записей без достаточной кривой/с запретом подбора остаются в базе, но не выдаются как подходящие насосы.
- Для прайсовых цен учитываются валюта и настройки скидок проекта. Снимки готовых закупочных цен (`priceKind=net`) не дисконтируются повторно. Сохранённые пользовательские курсы/скидки не заменяются новыми значениями по умолчанию.

## Файлы

- `app/pump-card-supplement.json` — дополнительные данные для карточки: масса из исходной SQLite и исполнений, диаметры из исходных записей, варианты присоединений. Обновляется перед сборкой командой `node scripts/build-pump-card-supplement.mjs`. Точное исполнение имеет приоритет; разные массы исполнений показываются отдельно. Размеры резьбы сохраняются как в источнике, без подмены их диаметром в мм.

- `public/pumps.json` — рабочая проекция для браузера. Она не содержит тяжёлый архив исходных записей.
- `app/pump-nozzles.json` — индекс параметров всасывающих и напорных патрубков, обновляется перед сборкой командой `node scripts/build-pump-nozzles.mjs`.
- `data/pump-catalog/cnp-physical-data.json` — проверенные дополнительные массы и присоединения CNP с происхождением каждого значения. Импортёр дополняет ими только отсутствующие физические поля при точном совпадении модели/исполнения; кривые, цены и ID не заменяются.
- `data/pump-catalog/legacy-pumps.json` — неизменяемая основа прежнего каталога.
- `data/pump-catalog/records.json` — все исходные поля и происхождение нормализованных значений, индекс по ID.
- `data/pump-catalog/conflicts.json` — журнал замен значений источником.
- `app/imported-pump-ports.json` — подтверждённые патрубки CNP из новых технических данных; неуказанные соединения не угадываются.
- `public/reference-pump-assets/` и `asset-manifest.json` — копии исходных документов и изображений с контрольными суммами.
- `remote-drawings.json` — результаты загрузки внешних чертежей. Успешно сохранены 895 URL; 264 недоступны (404/тайм-ауты). Один URL может относиться к нескольким моделям.
- В локальной папке `../database/` созданы `calculator-nu-source.sqlite` (неизменённая копия источника) и `pumps-merged.sqlite` (таблицы `catalog_models`, `catalog_curve_points`, `catalog_metadata`). Прежняя `pumps.sqlite` не изменялась. Эта папка находится за пределами Git worktree `frontend`; переносимая версия объединённых данных хранится в JSON выше.

## Эскизы и ограничения

Сначала используется модельный чертёж нового источника; при его отсутствии сохраняются старые подтверждённые изображения и справочные листы серий. Чертежи муфт/АТМ/УПМ не подменяют эскиз насоса. Индивидуальный чертёж CNP другого исполнения не выдаётся за чертёж нового FSWPC: используется явно обозначенный справочный лист серии. Семейство EVS не получает чертёж EVR по предположению.

Наличие кривой не означает инженерную сертификацию исходных данных. Пересчитанные с другой модели кривые ONIS помечены предупреждением. У части моделей источник не содержит эскиза; недоступные внешние изображения показывают сообщение об ошибке. Актуальные размеры исполнения и совместимость соединений необходимо сверять с техническими полями и паспортом, а не со справочной картинкой.

## Повторная сборка

Для обычного запуска и сборки приложения повторный импорт не нужен: рабочие JSON и сохранённые эскизы уже находятся в Git.

Для импорта требуется отдельная доступная копия `calculator-nu` с `data/app/pumps.db` и исходными каталогами. Для воспроизведения текущего объединения используйте commit, указанный выше. Папка `../database/` должна существовать; для сохранения дополнительных сведений старой SQLite в ней должна находиться прежняя `pumps.sqlite`. Без неё импортёр пропустит эти сведения, даже если они присутствовали в ранее сгенерированном `records.json`.

Перед импортом сохраните изменения JSON в Git и сделайте резервную копию внешних SQLite: команда заново формирует JSON, заменяет содержимое `pumps-merged.sqlite` и копию `calculator-nu-source.sqlite`. Прежняя `pumps.sqlite` читается без изменения.

Из `frontend`, Python 3, без сторонних Python-зависимостей:

```powershell
python scripts/merge-pump-catalogs.py --source ../reference-calculator-nu
python scripts/cache-pump-drawings.py
python scripts/merge-pump-catalogs.py --source ../reference-calculator-nu
python -m unittest discover -s tests -p 'test_*.py'
npm test
```

Импортёр не выполняет код исходного репозитория и не меняет его базу. Повторный импорт использует `legacy-pumps.json`, а не уже объединённый каталог. Не удалять эту основу. Старый `../database/export_pumps_for_frontend.py` экспортирует только прежнюю базу и не должен перезаписывать объединённый `public/pumps.json`.

Загрузка изображений идёт только с доменов, указанных в базе (ONIS/VANDJORD), с проверкой TLS и формата файла. Для выборочного повтора есть `--retry-pattern`. Недоступность внешних сайтов не блокирует автономную работу уже сохранённых изображений и кривых.
